# AI Usage and Prompt Documentation

## 1. AI Tool Used

**Tool:** ChatGPT

ChatGPT was used as an AI assistant during the development of the TrustVault project.

## 2. Purpose of AI Usage

AI assistance was used for:

- Understanding Django project structure.
- Planning document management features.
- Understanding authentication and authorization.
- Implementing document upload and download functionality.
- Understanding read and edit permissions.
- Implementing audit logging.
- Debugging errors and resolving configuration issues.
- Preparing project documentation.

## 3. Representative Prompts Used

The following prompts summarize the types of questions asked during development. They are representative examples, not a verbatim export of every conversation.

### Prompt 1: Project Planning
"Help me develop a Secure Document Sharing System using Python and Django. Explain the project structure and required modules."

### Prompt 2: Database Models
"Help me create Django models for documents, document permissions, and audit logs."

### Prompt 3: Authentication
"Explain how to implement user login and protect document-related views using Django authentication."

### Prompt 4: Access Control
"Help me implement document ownership checks and read/edit permissions so unauthorized users cannot access documents."

### Prompt 5: File Upload Security
"Explain how to validate uploaded file extensions and file sizes in Django."

### Prompt 6: Audit Logging
"Help me record document upload, download, and permission-sharing activities in an audit log."

### Prompt 7: Debugging
"Help me troubleshoot Django migration, URL routing, login, and configuration errors."

### Prompt 8: Documentation
"Help me prepare README, security documentation, and project setup instructions."

## 4. How AI Assistance Was Used

AI-generated suggestions were reviewed and applied during development. The project was run locally, and Django system checks and manual testing were performed as part of development.

The developer is responsible for understanding, reviewing, testing, and maintaining the final implementation.

## 5. Limitations

- AI-generated code may require corrections.
- Security recommendations must be tested before production use.
- File extension validation alone does not guarantee that an uploaded file is safe.
- Production deployment requires additional security configuration.

## 6. Conclusion

AI assistance helped improve development understanding, debugging, and documentation. The final project implementation and testing remain the developer's responsibility.
